# APC site redesign (visual spec)

This folder holds the winning lane A (round 3) output from the APC desktop site design bake-off (`prototype/`, `prototype-v1/`, `prototype-v2/`, `proposal.md`, `REV2.md`, `REV3.md`, and the Pulse hero data fixtures in `context/pulse/`). It is the visual spec for the "the standard's new site" wave so parallel authors share one exact reference; nothing in `sandbox/` is built, linted, or typechecked, and the PR closing the wave deletes this folder.
